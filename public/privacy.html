적용 범위와 처리 주체

이유준은 「개인정보 보호법」 제30조와 개인정보보호위원회 작성지침의 기재 항목을 참고해 Clip Memo(ClipMemo) 로컬 전용 Windows 앱과 소개·다운로드 웹사이트의 실제 정보 처리 방식을 안내합니다. Microsoft Store에서 제공하는 앱을 기준으로 하며 로그인·클라우드 동기화 기능은 포함하지 않습니다.

앱은 사용자의 PC에서 메모를 작성·저장하고 클립보드를 기록하는 도구입니다. 개발자는 앱을 통해 메모나 복사 기록을 서버로 제출받지 않으며, 이를 보관하는 회원·메모 서버를 운영하지 않습니다. 앱에서 데이터를 처리하는 것과 개발자가 데이터를 수신하는 것은 구분됩니다.

첫 실행의 클립보드 수집 기본값은 켜짐입니다. 수집을 원하지 않으면 클립보드 패널 스위치나 트레이 메뉴에서 일시정지하세요. 앱이 꺼져 있거나 수집이 정지된 동안에는 새 기록을 수집하지 않습니다. 중지 전에 저장한 기록은 별도 삭제할 수 있습니다.

앱은 민감정보를 자동으로 모두 구분하지 못합니다. 비밀번호·금융정보·건강정보처럼 민감한 내용을 복사하기 전에는 수집을 끄고, 원치 않는 기록이 저장되면 해당 항목을 삭제하세요.

보유 기간과 저장 위치

  • 메모: 사용자가 영구 삭제할 때까지. 내용이 있는 메모는 창이나 패널을 닫아도 유지합니다.
  • 일반 복사 기록: 생성 시각 기준 7일. 앱 시작 시와 실행 중 주기적으로 만료 기록을 정리하므로 앱이 꺼져 있는 동안에는 파일이 남을 수 있습니다.
  • 고정 기록: 직접 삭제하거나 고정을 해제할 때까지. 해제 후에는 원래 생성 시각에 따른 7일 규칙을 적용합니다.
  • 설정·오류·복구용 사본: 사용자가 데이터 폴더를 삭제하거나, 해당 파일을 교체·정리하는 앱 동작이 수행될 때까지. 오류 로그와 수동 백업에는 별도 자동 만료 기간을 설정하지 않습니다.

현재 위치는 설정 → 데이터 폴더 열기에서 확인합니다. 기본 저장 위치는 %LOCALAPPDATA%\Packages\<패키지 패밀리 이름>\LocalState\ClipMemo입니다. 사용자 지정 저장소나 이전 버전 저장소를 이어 쓰는 경우 실제 위치가 다를 수 있습니다.

파기 절차와 방법

메모 메뉴의 영구 삭제와 복사 기록의 삭제 버튼은 해당 목록과 연결 파일을 삭제합니다. 만료 기록도 앱에서 같은 정리 절차를 수행합니다. 삭제 시 저장·파일 권한 오류가 발생하면 정리가 완료되지 않을 수 있으므로 오류 안내와 데이터 폴더를 확인하세요.

전체 데이터를 지우려면 앱을 완전히 종료한 뒤 실제 데이터 폴더 전체를 삭제하세요. 별도로 만든 백업, Windows나 백업 프로그램의 사본은 따로 삭제해야 합니다. 앱의 일반 파일 삭제는 복구를 방지하는 보안 덮어쓰기를 의미하지 않습니다.

앱 제거·초기화 시 메모와 설정도 삭제됩니다. 중요한 메모는 먼저 별도로 백업하세요.

제3자 제공·처리 위탁·국외 처리

앱의 메모와 복사 기록: 개발자나 제3자 서버로 자동 전송하지 않습니다. 이 내용을 서버에 저장·분석하도록 맡기는 수탁자나 국외 이전은 없습니다. 광고·방문 분석 SDK, 회원가입, 클라우드 동기화 기능도 포함하지 않습니다.

웹사이트 제공: 소개 페이지와 다운로드 파일은 GitHub Pages에서 제공하며, 소개 페이지는 Google Fonts에서 글꼴을 불러옵니다. 방문자의 브라우저가 이들 서비스에 직접 접속하므로, 앱의 로컬 데이터 처리와 구분해야 합니다.

  • GitHub, Inc. / GitHub Pages: 웹페이지·파일 전송 및 보안 목적의 접속 기술 정보를 처리할 수 있습니다. IP 주소·요청 정보, 제공업체의 처리·보관·권리 행사 방식은 GitHub 개인정보처리방침에서 확인할 수 있습니다.
  • Google / Google Fonts: 소개 페이지 방문 시 글꼴을 제공하기 위한 요청이 발생합니다. 관련 처리는 Google 개인정보처리방침을 따릅니다. 이 방침 페이지는 시스템 글꼴만 사용합니다.

웹 접속과 글꼴 요청은 해외 서비스의 서버에서 처리될 수 있습니다. 개발자는 해당 서비스의 실제 서버 위치나 접속 로그 보관기간을 직접 지정·관리하지 않습니다. 브라우저에서 외부 글꼴 요청을 차단하면 시스템 글꼴로 표시되며, 웹사이트를 이용하지 않아도 설치된 로컬 앱은 사용할 수 있습니다. 웹사이트에서 메모·클립보드 내용을 읽지는 않습니다.

사용자가 외부 링크를 열거나 Microsoft Store·Windows 기능을 이용할 때의 브라우저 접속, 설치·업데이트·운영체제 진단은 해당 서비스 정책과 사용자 설정에 따릅니다.

안전성 확보조치와 한계

앱은 메모와 복사 기록을 PC 내부에 저장하고 자동 업로드하지 않습니다. 수집 일시정지·개별 삭제·전체 데이터 삭제 방법을 제공하며, 저장 중 파일 손상을 줄이기 위해 임시 파일 작성과 파일 교체 방식을 사용합니다.

앱 자체의 파일 암호화·비밀번호 잠금·보안 삭제 기능은 제공하지 않습니다. PC에 대한 접근 보호는 Windows 사용자 계정, 파일 권한과 사용자가 설정한 디스크 보호에 따릅니다. 공유 PC와 백업 파일 접근 권한을 직접 관리하세요.

자동 수집 장치와 적용하지 않는 처리

앱과 이 사이트에 개발자가 설치한 광고 추적·행태정보 분석 스크립트, 광고 식별자 수집, 자동 로그인 쿠키는 없습니다. 브라우저의 쿠키·사이트 권한은 브라우저 설정에서 관리할 수 있습니다. 호스팅·글꼴 제공 서비스의 처리는 앞 항목과 구분됩니다.

가명정보 분석, 개인정보를 이용한 자동화된 권리·의무 결정, 고정형·이동형 영상정보처리기기 촬영은 하지 않습니다. 캡처 이미지는 사용자가 붙여넣거나 클립보드에서 제공한 이미지를 처리하며, 앱이 카메라로 촬영하지 않습니다.

회원가입이나 나이 확인으로 아동 정보를 따로 수집하지 않습니다. 아동·미성년자의 PC에 저장된 내용도 동일한 로컬 저장 방식으로 처리하며, 법정대리인은 아래 권리 행사·문의 경로를 이용할 수 있습니다.

Scope and operator

Yujun Lee (이유준) publishes this policy for the local-only Clip Memo (ClipMemo) Windows app and its information/download website. It covers the app distributed through Microsoft Store. The app has no accounts or cloud synchronization.

The app edits notes and keeps clipboard history on your PC. The developer does not receive this content through an app server or operate an account/note database for this edition. Local app processing is distinct from sending data to the developer.

Purposes, information and processing

Information stored on your PC

The developer does not separately collect account, login, payment or advertising identifier data through an app server. This policy does not treat using the app as blanket consent to disclose personal information, and it does not replace any separate consent that may be required.

Clipboard capture is enabled by default on first use. Pause it with the panel switch or tray menu if you do not want capture. No new items are captured while the app is closed or capture is paused. Previously saved items can be deleted separately.

The app cannot identify all sensitive clipboard content. Pause capture before copying passwords, financial or health information, and delete any unwanted captured items.

Retention and storage

  • Notes: until you permanently delete them. Closing a panel/window keeps nonempty notes.
  • Unpinned clipboard items: 7 days from their original capture time. Cleanup runs at startup and periodically while running; files may remain while the app is closed.
  • Pinned items: until you delete or unpin them. Unpinning restores the 7-day rule based on the original capture time.
  • Preferences, errors and recovery copies: until you delete the data folder or the app replaces/cleans up those files. Error logs and manual backups have no separate automatic expiry.

Find your current location under Settings → Open data folder. The default data location is %LOCALAPPDATA%\Packages\<package family name>\LocalState\ClipMemo. A custom or legacy location may differ.

Deletion procedure and method

The permanent note deletion command and clipboard delete button remove the item and its linked files. Expired history uses the same cleanup process. Save/permission errors can prevent cleanup; check any error notice and your data folder.

To remove all data, quit the app completely and delete its actual data folder. Manage separate backups and copies made by Windows or backup tools separately. Ordinary file deletion is not secure overwriting that prevents recovery.

Before uninstalling or resetting the app

Uninstalling or resetting the app removes its notes and preferences. Back up important notes first.

The developer does not remotely store or erase your PC's data.

Third parties, outsourcing and overseas processing

App notes and clipboard history: no automatic upload to developer or third-party servers. No contractor or overseas service is used to store/analyze this content. The app has no advertising/analytics SDK, accounts or cloud synchronization.
